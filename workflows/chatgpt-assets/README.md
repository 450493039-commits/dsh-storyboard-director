# 短剧工作流 · ChatGPT 生图与即梦交接

剧本、分镜和参考图在同一个本地制作目录里审核。ChatGPT 生成的参考图保存到 Mac，定稿后上传到即梦短剧工作室。即梦积分留给视频生成。每批先完成各集制作和审核，等整批定稿后统一导出做后期。

| 阶段 | 制作内容 | 审核后才能进入下一步 |
| --- | --- | --- |
| 1. 剧本 | 在 ChatGPT 定稿，写清人物关系、剧情转折、对白、画幅和目标时长。 | 确认故事和对白。 |
| 2. 分镜 | 按时间写明每次切镜的景别、视线、表情和动作。把台词与反应镜头分别排到时间轴上。30 秒试拍可拆成两段 15 秒，每段内照样切镜。 | 确认分镜、节奏、切点和两段接缝。 |
| 3. 视觉资产 | 只做分镜实际需要的角色、场景和道具。角色先定脸、发型、服装、各视角和音色设定。场景先定布局、光向和机位，道具先定外观和状态。ChatGPT 生图后保存到 Mac。 | 审核选定的参考图，同一角色、场景和道具跨段用同一个资产 ID 和同一张定稿图。 |
| 4. 即梦分集生成 | 一部剧用一个项目，共用角色、场景和道具。进「分镜 → 分集视频」，打开对应集的故事板，按导入清单逐段绑定参考图、填写提示词、设置时长。核对参考图顺序和积分报价后提交。验收首段后，可把实际尾帧作为下一段的补充参考，并保留分镜规定的机位。 | 按集审核角色、场景、道具与接缝。记录要改的集号和片段号，只重跑对应段。 |

## 分镜依据

沿用 [ai-comic-drama-director-skills](https://github.com/djyy1031/ai-comic-drama-director-skills/tree/47df36773100ae8f39f91b253bcf15b0291060a3) 的导演和连续性规则。分镜应交代每次切镜的理由和画面变化，按切点检查人物左右位、视线、动作衔接、光线和道具状态。人物音色在角色设定里集中维护。输出给即梦的每段提示词在确认分镜后再写。

## 每集资料和导入

把 [清单模板](manifest.example.json) 复制到短剧制作目录，新建每集清单、剧本、分镜和段落提示词。连续段或跨集复用的参考图可以放在同一制作目录的公共资产文件夹，由各集清单引用。

示例清单是 30 秒、两段 15 秒。每段在 `references` 里写出真实的上传或绑定顺序。提示词里的 `@图片1` 对应第一张，`@图片2` 对应第二张，以此类推。角色、场景和道具用各自的资产 ID。参考尾帧用 `continuity`；需要补入尾帧时，等上一段生成并审过再更新下一段。任一阶段改稿，先撤回对应确认和受影响的后续确认。

审核完后，将清单里的三项 `approved` 设为 `true`，用 Python 3.10 或更新版运行下列命令。带空格的实际路径需要保留引号。

```bash
python3 workflows/chatgpt-assets/prepare.py "/制作目录/第01集.json" "/制作目录/第01集-即梦导入包.zip"
```

导入包包含剧本、分镜、每段提示词、定稿参考图和中文绑定清单。脚本检查审核状态、文件、时长和 `@图片N` 的对应关系。解压后上传当集新增的定稿参考图，已有资产从项目资产库复用。进入当集故事板生成和审核，确认该集采用的片段版本，然后继续制作下一集。[即梦分集与资产管理说明](https://jimeng.jianying.com/tutorials/drama-studio/product-manual)

画布用于单独试镜和做复杂场面。《婚礼取消》已有的两段画布视频仍可用剪映草稿审核。测试时两段都能在分集编辑器的资产库里看到，但未找到把它们直接登记为分镜成片的入口。

## 整批定稿后的剪映后期

等这一批各集都审核通过后，再统一导出视频，按集号和片段号归档。比如本批做第 01–10 集，就等这十集都定稿，再启动剪映。素材和工程按集对应，字幕样式统一，后续可按集单独修改。

首选验证 [Jianying Local MCP](https://github.com/Capricornus-joe/jianying-local-mcp/tree/f47f907e7bc15e68082238e50ca5964c50b2f559)。它接收本地视频素材和已定时的 SRT，可在 Mac 上按顺序组装独立片段、添加原生字幕轨并批量套样式。使用通过审核的各段原片建一个新草稿。首次先做本地预检，再使用已生成的 30 秒试片确认当前剪映版本能打开草稿并编辑字幕。最终导出在剪映内完成。

- **断句**　默认一屏一行、每条 6–12 个汉字。短对白可以更短，超过 14 字优先按语意和停顿拆开。人名、金额和专有词尽量连在一起，换人说话另起一条。保留原声中的「呢」「吧」等语气词，画面上的对白字幕去掉标点。
- **时间**　先定最终切点，再从各段原声识别对白，按成片时间轴换算。逐句结合语音活动和波形复核首字的实际发声，字幕入点落在听到首字的那一帧附近。重点复查停顿后、换人和段落接缝处，剪映预览时抽听首句、接缝和末句。剧本用于校正人名、金额和同音错字。对白跨镜时可以延续字幕，反应镜头无对白时留空。
- **样式**　对白统一大号白字黑描边、底部居中，上移避开竖屏平台界面。720 × 1280 草稿的 Jianying Local MCP 字号参数从 64 起，首集预览确认最长一句能在安全区域内单行显示，再沿用到全剧。
- **交付**　保留剪映原生可编辑字幕轨和一份 SRT。若工具生成的草稿与本机剪映版本不兼容，用已验证的即梦草稿交付路线，在剪映里导入同一份 SRT 并套同一套样式。
